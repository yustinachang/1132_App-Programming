# FinalApplication3 壓縮檔來源版本

從本機 `FinalApplication3.zip` 保留的 CubeClub／ClueCube Android 專案版本。收錄 54 份來源、建置設定及資源，其中 10 份檔案與 [主要專案](../../Final_Project/ClueCube) 的既有版本不同；兩個版本分開保存，未據此判定哪個較新。

使用 Android Studio 開啟此資料夾。機器專屬的 `local.properties`、IDE 與編譯快取不屬於此來源版本；請在自己的電腦重新同步 Gradle，設定 Android SDK。

來源壓縮檔與每份來源檔案的校驗碼見 [SOURCE_MANIFEST.json](SOURCE_MANIFEST.json)。此次保存只核對來源與 XML 完整性，未重新建置或操作 Android 應用程式。
